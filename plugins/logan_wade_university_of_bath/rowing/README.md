# Rowing Plugin

Author: Logan Wade, University of Bath

This movement plugin contains ergometer rowing segmentation and result
generation code. Graph export will be added after the gait graph schema workflow
has been finalised.

## Files

- `ergo_rowing_analysis.py`: rowing event detection and movement-specific analysis.
- `ergo_rowing_results.py`: rowing result calculation and result dictionary creation.
- `assets/`: movement-specific images or visual assets used by graph displays.
