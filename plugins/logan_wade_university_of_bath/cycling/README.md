# Cycling Plugin

Author: Logan Wade, University of Bath

This movement plugin contains ergometer cycling segmentation and result
generation code. Graph export will be added after the gait graph schema workflow
has been finalised.

## Files

- `ergo_cycling_analysis.py`: cycling event detection and movement-specific analysis.
- `ergo_cycling_results.py`: cycling result calculation and result dictionary creation.
- `assets/`: movement-specific images or visual assets used by graph displays.
