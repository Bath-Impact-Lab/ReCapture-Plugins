# Sit-To-Stand Plugin

Author: Logan Wade, University of Bath

This movement plugin contains sit-to-stand segmentation and result generation
code. Graph export will be added after the gait graph schema workflow has been
finalised.

## Files

- `sit_to_stand_analysis.py`: sit-to-stand event detection and movement-specific analysis.
- `sit_to_stand_results.py`: sit-to-stand result calculation and result dictionary creation.
- `assets/`: movement-specific images or visual assets used by graph displays.
